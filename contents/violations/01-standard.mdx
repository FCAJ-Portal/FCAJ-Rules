| Hạng mục            | Điểm                       |
| ------------------- | -------------------------- |
| Điểm chuyên cần     | **1 điểm** (0.1 điểm/buổi) |
| Điểm thái độ        | **1 điểm**                 |
| Điểm tác phong      | **1 điểm**                 |
| Điểm tham dự event  | **1 điểm**                 |
| Điểm dự án thực tập | **6 điểm**                 |
| **Tổng**            | **10 điểm**                |

:::info
Yêu cầu điểm tổng kết **tối thiểu 7.0/10** để được xét chứng nhận hoàn thành thực tập.
:::

:::note[Bảng gốc để chấm điểm]
Bảng này chia điểm theo hạng mục. **Barem gốc** để chấm là [Tiêu chí chấm điểm](/scoring). Mức trừ của từng vi phạm xem tại [Xử lý vi phạm](/violations).
:::
