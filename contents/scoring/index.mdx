Tài liệu này mô tả **barem tổng quan** và **các quy tắc / lưu ý quan trọng** trong quá trình đánh giá kết quả thực tập dành cho sinh viên tham gia chương trình First Cloud AI Journey (FCAJ). Sinh viên cần nắm vững các tiêu chuẩn và các trường hợp bị điểm liệt / trừ điểm để hoàn thành tốt kỳ thực tập.

## Barem tổng quan

| Nhóm tiêu chí       | Điểm tối đa | Ghi chú                      |
| ------------------- | ----------- | ---------------------------- |
| Worklog / Blog      | **1.0**     |                              |
| Proposal / Workshop | **5.0**     | Architecture chiếm tỷ lệ cao |
| Thái độ / tác phong | **2.0**     |                              |
| Chuyên cần          | **1.5**     |                              |
| Bonus               | **0.5**     | Chỉ cộng khi đủ điều kiện    |
| **TỔNG**            | **10.0**    |                              |

:::info
Yêu cầu điểm tổng kết **tối thiểu 7.0/10** để được xét duyệt tham gia **Chương trình FCAJ Challenger**.
:::

## Vi phạm nội quy trừ vào đâu

Đây là barem gốc. Vi phạm nội quy được trừ vào các mục sau. Mức trừ cụ thể xem [Xử lý vi phạm](/violations).

| Vi phạm                                              | Trừ vào                                |
| ---------------------------------------------------- | -------------------------------------- |
| Vi phạm trang phục                                   | Thái độ / tác phong                    |
| Vi phạm di chuyển trong văn phòng                    | Thái độ / tác phong                    |
| Vi phạm ăn uống / sử dụng đồ dùng                    | Thái độ / tác phong                    |
| Check-in trễ, đăng ký portal nhưng không lên         | Chuyên cần                             |
| Tự ý bỏ về giữa chừng / nghỉ trưa xong về luôn       | **Tổng điểm cuối cùng** (trừ 2 điểm)   |

:::danger[Trừ 2 điểm trên tổng điểm]
Sau khi chấm Project và có điểm cuối cùng, team admin rà lại và **trừ thẳng 2 điểm** cho mỗi lần tự ý bỏ về giữa chừng hoặc nghỉ trưa xong về luôn.
:::
